--------------------------------------------------------------------------------
  BLOCO 1 - VICTOR - 0:00 a 1:10 - Evolucao, arquitetura e tecnologias
--------------------------------------------------------------------------------

  TELA: Slide de abertura.

  "HidroVigia: vigilancia da qualidade da agua em sistemas de abastecimento
   de pequeno porte, alinhado ao ODS 6, agua potavel e saneamento. Os limites
   que o sistema aplica sao os da Portaria GM/MS 888 de 2021 - nao ha criterio
   inventado pela equipe.

   Na primeira entrega mostramos o fluxo principal: registrar a coleta, abrir
   a ocorrencia com prazo e trata-la ate o fim. Mas esse fluxo so enxerga o
   que foi medido. Um ponto que deixa de ser amostrado nunca reprova nada - e
   some do radar. E uma ocorrencia so aparece quando o desvio ja aconteceu.

   Nesta entrega o sistema passou a enxergar as duas coisas: o ponto esquecido,
   com o alerta de coleta vencida, e a tendencia antes do desvio, com a serie
   historica de cada parametro."

  TELA: Slide de arquitetura e tecnologias.

        +-----------------------------------------------------------+
        |  React 19 + TypeScript   (interface, no mesmo jar)        |
        |        | HTTP                                             |
        |  api/        Spring Boot 3 - controllers REST + Swagger   |
        |  servico/    casos de uso                                 |
        |  repositorio/ Spring Data + agregacao                     |
        |  dominio/    Java 21, sem Spring                          |
        |        |                                                  |
        |  MongoDB 7 - 3 colecoes                                   |
        |                                                           |
        |  Testes: JUnit 5, Mockito, Testcontainers, Vitest,        |
        |          Playwright  -  Cobertura: JaCoCo  -  CI: Actions |
        +-----------------------------------------------------------+

  "A arquitetura final: uma interface React servida pelo mesmo jar do Spring
   Boot, em Java 21, sobre MongoDB 7. As camadas dependem sempre para dentro:
   o dominio, onde ficam as regras da norma, nao conhece o Spring - por isso
   ele e testado sem subir nada. E e ali que estao os padroes de orientacao a
   objetos: Template Method e polimorfismo nos parametros, Strategy na
   gravidade, State no ciclo da ocorrencia."

--------------------------------------------------------------------------------
  BLOCO 2 - BRUNO - 1:10 a 2:10 - Banco: indice, agregacao e o defeito
--------------------------------------------------------------------------------

  TELA: Mongo Express, colecao 'analises', um documento ja expandido.

  "Tres colecoes - pontos, analises e ocorrencias - relacionadas por
   identificador, com subdocumentos aninhados em todas. Cada parametro medido
   guarda o limite que foi aplicado: norma muda, e uma analise de 2026 precisa
   continuar mostrando o limite de 2026.

   Nesta entrega o banco ganhou um indice composto, ponto e data de coleta
   decrescente. E a consulta mais frequente: o historico de um ponto. O alerta
   de coleta vencida busca a ultima coleta de cada ponto, e ela e o primeiro
   item desse indice."

  TELA: docs/modelagem-nosql.md, secao "Agregacao", com o pipeline visivel.

  "A serie historica e calculada pelo proprio MongoDB, num pipeline de
   agregacao: filtra o ponto e o periodo, desdobra o array de parametros e
   agrupa por dia com minimo, media e maximo. Um detalhe: o valor e gravado
   como texto, para nao perder casas decimais. Comparado como texto, 10,5 e
   menor que 9. Por isso o pipeline converte para decimal antes - e o teste de
   integracao, contra um MongoDB de verdade, cobre exatamente esse caso.

   E falando em teste de integracao: nesta entrega descobrimos que eles
   estavam sendo pulados em silencio. O Docker novo passou a recusar a versao
   de API que o projeto pedia, o Testcontainers entendeu que nao havia Docker,
   e o build ficava verde sem ter encostado no banco. Corrigimos, e a CI
   reprova se qualquer suite for pulada."

  DICA: essa ultima frase e a mais forte do bloco. Suite que nao roda parece
        suite que passa.
